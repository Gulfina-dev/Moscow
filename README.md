# Moscow Tours

## Description
A student project website for tours and excursions in Moscow. The design is inspired by a Pinterest concept originally created for Rome, but fully adapted for Moscow with original content, custom photos, and Russian text.

This project was created as part of a college assignment to practice layout, styling, and responsive design.

> **Design reference**: The original layout was inspired by a Pinterest concept (Rome). All code and content were written and adapted from scratch for educational purposes.

## Technologies Used
- HTML5
- CSS3 (Flexbox, Grid)
- JavaScript (vanilla, no libraries)

## Features
- Hero section with a "Book Now" button
- Booking pop-up (phone input, demo-only)
- Information about Moscow with landmarks
- Excursions section (planned: booking buttons)
- Customer reviews slider
- Footer with map image and social media icons (non-functional, planned updates)
