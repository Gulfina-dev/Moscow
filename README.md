## 🇬🇧 English

# Moscow Tours

## Description
A student project website for tours and excursions in Moscow. The design is inspired by a Pinterest concept originally created for Rome, but fully adapted for Moscow with original content, custom photos, and Russian text.

This project was created as part of a college assignment to practice layout, styling, and responsive design.

> **Design reference**: The original layout was inspired by a Pinterest concept (Rome). All code and content were written and adapted from scratch for educational purposes.

## Technologies Used
- HTML5
- CSS3 (Flexbox, Grid)
- JavaScript (vanilla, no libraries)

## Features
- Hero section with a "Book Now" button
- Booking pop-up (phone input, demo-only)
- Information about Moscow with landmarks
- Excursions section (planned: booking buttons)
- Customer reviews slider
- Footer with map image and social media icons (non-functional, planned updates)

## Planned Improvements
- Add language switch (RU/EN)
- Make logo clickable
- Implement multi-image banner slider
- Add booking buttons for excursions
- Make the map interactive
- Connect social media icons to real profiles
- Add backend for booking form

## 🇷🇺 Русский

# Туры по Москве

## Описание
Учебный проект — сайт с турами и экскурсиями по Москве. Дизайн вдохновлён концепцией с Pinterest, изначально созданной для Рима, но полностью адаптирован под Москву с оригинальным контентом, своими фото и русским текстом.

Проект создан в рамках учебного задания для отработки вёрстки, стилизации и адаптивного дизайна.

> **Источник дизайна**: Макет вдохновлён концепцией из Pinterest (Рим). Весь код и контент написаны и адаптированы с нуля в образовательных целях.

## Используемые технологии
- HTML5
- CSS3 (Flexbox, Grid)
- JavaScript (чистый, без библиотек)

## Функциональность
- Главный баннер с кнопкой «Забронировать»
- Окно бронирования (ввод телефона, демо-версия)
- Информация о Москве с достопримечательностями
- Раздел «Экскурсии» (в планах: кнопки бронирования)
- Слайдер с отзывами
- Подвал с картинкой карты и иконками соцсетей (пока не работают)

## Планы по доработке
