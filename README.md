# Moscow Tours

## Description
A website with tours and excursions around Moscow. Browse available routes, read customer reviews, and book a tour (the booking form is demo-only — phone number is not actually sent, the window simply closes).

## Technologies Used
- HTML5
- CSS3 (Flexbox, Grid)
- JavaScript (vanilla, no libraries)

## Features
- Fully responsive design (mobile-friendly)
- Working navigation menu
- Reviews slider
- Demo booking form (phone input, pop-up closes without submission)
- Tour gallery with routes

## Future Improvements
- Connect real booking submission (Telegram bot or email)
- Add tour filters (by price, duration, type)
- Moscow map integration
